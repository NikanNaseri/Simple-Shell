# SimpleShell 🐚

SimpleShell is a lightweight command-line shell written in Python.  
This project provides a simple environment for executing basic file and directory management commands.

It is designed as a beginner-friendly project for practicing Python programming, functions, file handling, directory management, exception handling, and user input processing.

## Features

SimpleShell supports the following commands:

| Command | Description |
|--------|-------------|
| `pwd` | Displays the current working directory |
| `ls` | Lists files and directories in the current directory |
| `cd <path>` | Changes the current directory |
| `ni <file_name>` | Creates a new file |
| `mkdir <directory_name>` | Creates a new directory |
| `rm <file_name>` | Removes a file |
| `rmdir <directory_name>` | Removes an empty directory |
| `cat <file_name>` | Displays the contents of a file |
| `exit` | Exits the shell |

## Requirements

- Python 3.x
- Windows operating system

## How to Run
1.Make sure you have Python installed.
2.Run the game using: python SimpleShell.py
